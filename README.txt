JAYATI — MEA CONSULTANT PORTFOLIO

This website now includes your four supplied Instagram design samples.

FILES
- index.html: page content and gallery
- styles.css: design, responsive layout, and animations
- script.js: click-to-expand viewer, previous/next navigation, keyboard controls
- images/design-01.jpg through design-04.jpg: your four design samples

PREVIEW
Open index.html in a browser. The four cards open in a centered full-screen viewer. Use the arrows or keyboard arrow keys to browse, and Escape to close.

BEFORE PUBLISHING
- Replace hello@example.com in index.html with your preferred contact email (or remove the contact link).
- Review any factual statistics/text in the designs before public posting.

PUBLISH ON GITHUB PAGES
1. Create a new repository on GitHub, e.g. jayati-portfolio.
2. Upload index.html, styles.css, script.js, and the images folder with all four JPG files.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will show the published site URL in the Pages section.
